# claude-kit doctor

## `--library` (default)

```bash
node "${CLAUDE_PLUGIN_ROOT}/scripts/validate-library.mjs"
```

On success it prints one line: axes, fragments, slots, and how many legal
combinations were resolved **and rendered**. On failure it prints a bulleted list
of specific problems.

Report the output as-is. Each bullet names a file and the exact rule broken —
do not summarize them away or attempt fixes unless the user asks.

To also show what is currently supported:

```bash
cat "${CLAUDE_PLUGIN_ROOT}/library/axes.json"
```

Present it as a table of axis → options, and be explicit that anything not listed
is **not** supported yet.

## `--project`

Run inside a repo that claude-kit generated.

```bash
ls .claude-kit/answers.json .claude/ 2>/dev/null
```

If `.claude-kit/answers.json` is missing, this repo was not generated by claude-kit
(or the file was not committed). Say so and stop.

Otherwise re-resolve and compare against what is on disk:

```bash
node "${CLAUDE_PLUGIN_ROOT}/scripts/resolve.mjs" \
  --answers .claude-kit/answers.json --out /tmp/claude-kit-doctor-plan.json
node "${CLAUDE_PLUGIN_ROOT}/scripts/render.mjs" \
  --plan /tmp/claude-kit-doctor-plan.json --dry-run
```

Compare the dry-run's file list and hashes to `.claude/`. Report three categories
separately, because they mean different things:

- **Drifted** — a generated file whose content no longer matches. Either the library
  moved on, or someone hand-edited it. Say which files, not just how many.
- **Missing** — the library now emits a file this repo does not have.
- **Extra** — a file in `.claude/` the library does not emit. Often deliberate; flag,
  never delete.

Do not overwrite anything. Report, then let the user decide.
